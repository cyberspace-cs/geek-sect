🏗️ 系统设计思维修炼
系统设计不是背答案，而是从需求到架构的推导过程。掌握以下思维模型：
📐 四步设计法
1. 需求澄清：功能需求 + 非功能需求（QPS/延迟/可用性）
2. 容量估算：读QPS/写QPS/存储量/带宽
3. 高层设计：客户端→网关→服务→存储，画核心组件
4. 深入设计：选数据结构、设计API、扩展性、容错
🔑 核心设计权衡
• CAP：分布式系统选CP还是AP？
• 缓存 vs DB：读多写少用缓存，写多了要考虑一致性
• 同步 vs 异步：同步简单但慢，异步快但复杂
• 强一致 vs 最终一致：金融要强一致，社交可以最终一致

💡 面试加分点

  • 为什么用向量库？ → 语义搜索比 LIKE 快 100 倍
  • 缓存穿透怎么办？ → 布隆过滤器 / 空值缓存
  • 缓存击穿怎么办？ → 互斥锁 / 永不过期
  • 缓存雪崩怎么办？ → 随机 TTL / 多级缓存

🔍 二分查找系列
#704 二分查找
简单
💡 思路：有序数组找目标值，每次砍一半
⏱ 时间：O(log n)    💾 空间：O(1)
💡 模板：left=0, right=len-1, while left<=right
#33 搜索旋转排序数组
中等
💡 思路：二分 + 判断哪一半是有序的
⏱ 时间：O(log n)    💾 空间：O(1)
💡 关键：mid 和 left 比较，确定有序区间
👯 双指针系列
#1 两数之和
简单
💡 解法1：哈希表 O(n) · 解法2：双指针 O(n log n)
⏱ 时间：O(n)    💾 空间：O(n)
💡 哈希表法：边遍历边查 target - x 是否在表里
#15 三数之和
中等
💡 思路：排序 + 固定一个数 + 双指针找另外两个
⏱ 时间：O(n²)    💾 空间：O(1)
💡 去重：跳过相同的 nums[i], nums[left], nums[right]
#206 反转链表
简单
💡 思路：三个指针 prev, curr, next，逐个翻转
⏱ 时间：O(n)    💾 空间：O(1)
💡 递归法也能写，但迭代法面试更稳
🧮 动态规划系列
#70 爬楼梯
简单
💡 思路：斐波那契数列 dp[i] = dp[i-1] + dp[i-2]
⏱ 时间：O(n) · 可优化到 O(log n) · 💾 空间：O(1)
💡 状态压缩：只用两个变量存前两个状态
#121 买卖股票的最佳时机
简单
💡 思路：遍历，维护历史最低价，每天算最大利润
⏱ 时间：O(n)    💾 空间：O(1)
💡 本质：dp[i] = max(dp[i-1], price[i] - min_price)
#300 最长递增子序列
困难
💡 解法1：DP O(n²) · 解法2：二分+贪心 O(n log n)
⏱ 时间：O(n log n)    💾 空间：O(n)
💡 二分法：维护一个 tails 数组，tails[i] 是长度 i+1 的最小尾元素
🌳 二叉树系列
#144 二叉树的前序遍历
简单
💡 解法1：递归 · 解法2：迭代（栈）
⏱ 时间：O(n)    💾 空间：O(n)
💡 模板：根 → 左 → 右，栈法压右再压左
#102 二叉树的层序遍历
中等
💡 思路：BFS 队列，每层记录当前层的 size
⏱ 时间：O(n)    💾 空间：O(n)
💡 模板：while queue: size = len(queue)，循环 size 次
#236 二叉树的最近公共祖先
中等
💡 思路：后序遍历，左右分别找 p 和 q
⏱ 时间：O(n)    💾 空间：O(h)
💡 递归：if root == p or root == q: return root
